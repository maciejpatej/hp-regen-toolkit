    03 / FIRMWARE LAB
    Sprawdź, zanim wgrasz.
    Analiza lokalnego pliku. Żadne dane nie są wysyłane do drukarki.
    OFFLINE PREFLIGHT
    
        
    !
    Brak adaptera zapisu firmware
    Ta wersja nie flashuje i nie wykonuje jailbreaku. Wynik sprawdzenia sumy i modelu nie potwierdza autentyczności ani bezpieczeństwa obrazu.
    
        
    Przygotuj pakiet
    Manifest traktujemy jako niezaufane dane, a nie certyfikat producenta.
    Nie wystarczy sama marka ani nazwa serii.
    Wybierz lokalny plik binarny. Plik pozostaje na tym komputerze.
    Wymagane: schema_version (1), model, firmware_version, sha256, size, source_url (HTTPS).
    Format manifestu
    {
  "schema_version": 1,
  "model": "DOKŁADNY MODEL",
  "firmware_version": "WERSJA",
  "sha256": "64 znaki szesnastkowe",
  "size": 123456,
  "source_url": "https://example.org/firmware"
}
    ZANIM POWSTANIE ADAPTER
    Nie ma skrótów
    do bezpiecznego flashu.
    1. Zidentyfikuj sprzętDokładny model, rewizja i bootloader.
    2. Sprawdź źródło obrazuHash potwierdza zgodność pliku z manifestem, nie jego autentyczność.
    3. Zapewnij drogę powrotuKopia, recovery i fizyczna weryfikacja na konkretnym urządzeniu.
    ZAPIS: NIEDOSTĘPNY
    
        
    Wynik sprawdzenia
    Preflight nie jest zgodą na wgranie obrazu.
